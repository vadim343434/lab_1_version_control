# Лабораторна робота №1 — Робота з версійним контролем (Git)

## Опис проєкту

Цей репозиторій створено в межах лабораторної роботи №1 з теми «Робота з версійним контролем (Git)».

У репозиторії розміщено результати лабораторної роботи з дисципліни «Інтелектуальний аналіз даних»:

- `ЛР_1.ipynb` — ноутбук Google Colab із виконанням лабораторної роботи;
- `Сівак_AI241_ЛР 1.pdf` — протокол виконаної лабораторної роботи.

## Призначення

Репозиторій демонструє використання системи контролю версій Git для зберігання та керування файлами навчального проєкту, а також їх розміщення у віддаленому репозиторії GitHub.

## Використані технології

- Git
- GitHub
- Google Colab
- Jupyter Notebook
